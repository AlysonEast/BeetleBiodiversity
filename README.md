# BeetleBiodiversity

Analysis of ground beetle (Carabidae) species richness and sampling
completeness across NEON (National Ecological Observatory Network) sites,
plots, and domains, using rarefaction/extrapolation (Hill number q=0) to
estimate asymptotic species richness from pitfall trap abundance data.

## Overview

Ground beetles are sampled at NEON terrestrial sites using pitfall traps.
This repository uses the [`neonDivData`](https://github.com/daijiang/neonDivData)
R package (a curated, versioned snapshot of NEON beetle community data) to:

1. Estimate species richness and sample completeness at the **domain**,
   **site**, and **plot** level using rarefaction/extrapolation (`iNEXT`).
2. Examine how richness and completeness estimates change when computed
   per-year vs. pooled across years, and summarize inter-annual variability.
3. Map spatial patterns in estimated richness and completeness across NEON
   sites.
4. Illustrate conceptual expectations of richness patterns under niche,
   individual, and neutral community-assembly theories (simulated data, for
   figure/illustration purposes only — not fit to the NEON data).

## Data source

- **Source data:** NEON beetle (Carabidae) pitfall trap collection data,
  accessed via the [`neonDivData`](https://github.com/daijiang/neonDivData)
  R package (installed from `https://daijiang.r-universe.dev`), which
  provides a cleaned, standardized snapshot of the raw NEON data product
  [DP1.10022.001](https://data.neonscience.org/data-products/DP1.10022.001).
- **Supplementary spatial data:** NEON Terrestrial Observation System (TOS)
  plot centroid/polygon shapefiles (`All_NEON_TOS_Plot_*_V11_BET`), used for
  plot-level mapping.
- NEON data are provided under NEON's open data policy. This repository does
  not redistribute raw NEON data; scripts pull it through `neonDivData` at
  run time. See [Reproducibility](#reproducibility--data-versioning) for why
  the exact package version matters for reproducing published numbers.

Derived CSV outputs (`Site_annualVarWeightedMean_EstimatedSppRichness.csv`,

### Suggested run order

1. `RarefactionBySiteYear.R` — produces
   `Site_annualVarWeightedMean_EstimatedSppRichness.csv` and
   `Site_CompletnessCompare.csv`
2. `RarefactionByPlotYear.R` — produces
   `plot_annualVarWeightedMean_EstimatedSppRichness.csv`
3. `Site_SppRichness.R` — reads the CSVs above and produces summary maps/figures
4. `Theory_Figs.R` is illustrative/conceptual only and can be run independently

`Archive/` contains earlier drafts (`Rarefaction.R`, `RarefactionByYear.R`)
kept for provenance; they are superseded by the scripts above and are not
part of the run order.

## Reproducibility & data versioning

`neonDivData` bundles a **static snapshot** of NEON beetle data as of the
package's release date, rather than pulling live from the NEON API — this is
good for reproducibility, but only if the exact package version is recorded.
NEON continues to publish new beetle sampling bouts each year, so results
generated with a newer snapshot of `neonDivData` will differ from results
generated with an older one (more years/sites of data). Before/at
publication:

- Record the installed `neonDivData` version (`packageVersion("neonDivData")`)
  alongside the manuscript's results.
- Consider archiving the specific data snapshot used (e.g., alongside the
  code on Zenodo) so the analysis remains re-runnable even if the upstream
  package changes or is removed.
